# 🍌 Prompts de Génération d'Inspiration pour NanobananaPro / Midjourney

Ce guide contient les prompts exacts, optimisés et prêts à l'emploi pour générer des maquettes d'inspiration ultra-qualitatives sur **NanobananaPro** (ou Midjourney / Flux). Utilise ces rendus visuels comme références directes pour concevoir ensuite tes déclinaisons vectorielles finales sur **Canva**.

---

## 🎨 Rappel des Codes Couleurs à injecter dans les Prompts

## 💡 Méthode d'Utilisation dans Canva :
1. Lance 2 à 3 générations par prompt sur **NanobananaPro**.
2. Choisis la variation dont **l'équilibre géométrique** te plaît le plus.
3. Importe l'image générée dans Canva comme calque d'inspiration.
4. Dans Canva :
   - Recrée le symbole avec les formes vectorielles de base (triangles, lignes, ondes audio).
   - Utilise **Bricolage Grotesque** pour taper `SUPER4C2`.
   - Applique les codes couleurs exacts (`#E51A31`, `#0B132B`, `#00B4D8`).
   - Masque le calque d'inspiration et exporte en **PNG fond transparent**.
